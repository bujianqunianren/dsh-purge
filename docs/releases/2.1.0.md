# 2.1.0

## 宿主源码补丁层整体移除

v2.1.0 是本插件的架构分水岭：**从"可选写宿主"变为纯运行时插件**。
ALL_PATCHES = []，lib/patches/ 目录整体删除，本插件不再改写 DSH 安装目录。

### 移除内容

- **补丁表**：lib/patches/（六张表 + shared + index）全部删除；ALL_PATCHES 保持导出形状但恒为空数组。
- **宿主写入入口**：
  - purge_apply / purge_revert 工具注册删除；
  - /dsh-purge/apply | revert | restart | diagnose 四条路由删除；
  - /purge apply | revert 命令分支返回"v2.1.0 已移除"提示；
  - 启动自愈（settleInstalledPatches）跳过所有宿主写入逻辑；
  - autoApply / scheduleApplyRestart（asar 换包编排）删除。
- **selfcheck**：15 个宿主补丁层 + 布局层全部移除；自检只覆盖运行时注入层 + profile 权限参考层。
- **测试**：18 个纯补丁测试文件删除；fixtures/inject-clauses.json 更新为 v2.0.1 新模板的强制句。
- **shim 注入**：shimNeedsPatch 恒返回 false，不再修改 dsh / dsh.cmd / dsh.ps1。

### 保留内容

- **运行时注入链**（仅 unrestricted / redteam 预设）：提示词注入、强化段、能力协议、探针、拒绝重试、续跑——完整保留。
- **面板 / CLI**：status / selfcheck / boost / probe / audit / preset / rules / skills / rewind / backup / rollback / uninstall 保留。
- **红队演练台**：完整保留。
- **更新系统**：完整保留。

### 对用户的影响

- 安装后无需点「应用」——插件装好重启即生效；
- 不会出现"Host backup failed"——因为没有任何宿主写入操作；
- 审批、沙箱、文件围栏回到 DSH 官方行为。
